# Getting help

## Myntlo customers

Email [support@myntlo.com](mailto:support@myntlo.com) for help with your account, billing or using Myntlo.
GitHub issues are not monitored for customer support.

## Myntlo team members

- Bugs and feature requests: open an issue in the relevant repository using the templates.
- Questions about how to contribute: see [CONTRIBUTING.md](CONTRIBUTING.md).

## Security

Do not report security problems in issues.
See [SECURITY.md](SECURITY.md).
